# What's New in v6.0.2

## Fixes

- **Clearer message when you have no payroll sheet yet.** With Clario connected but no Matrix payroll sheet read, the blue bar said *"Your payroll sheets carry no pay rates, so dollar amounts stay hidden"* — about sheets you did not have. It now says *"No payroll sheet yet, so dollar amounts are hidden. Save your Matrix payroll sheet in Downloads, or click Add sheet."* The other message, for sheets that really contain no pay rates, is shorter too: *"Your payroll sheets have no pay rates in them, so dollar amounts are hidden. Add a recent Matrix payroll sheet."*
